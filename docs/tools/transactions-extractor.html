Transactions Extractor ​

The Transactions Extractor turns a bank or credit-card statement PDF, or a CSV or spreadsheet export, into structured transactions. It runs automatically whenever you add a source that looks like a statement, so most of the time you won't use it directly.

Use the tool itself to check a file before adding it: drop in a statement and see exactly what would be imported. The result is shown in the tool and can be saved as a local CSV file.

Parsers ​

Support for each statement format comes from an individual parser. OrbySystems ships with parsers for the common major institutions; see Supported institutions.

Parsers run in a sandbox with no network access, and can read only the one statement they're given.

If yours isn't supported, or reads a statement wrongly, use Add New Institution.
