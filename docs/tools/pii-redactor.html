PII Redactor ​

The PII Redactor strips personal information out of a document — useful when you want to share or save a sample statement (for example, to help build support for a new format) without exposing anything private.

How it works ​

  1. Drag and drop a PDF, CSV, or spreadsheet file onto the tool.
  2. Click Auto-detect to find likely personal information — names, account numbers, and similar details.
  3. Review and edit the list of detected items — add anything that was missed, or remove a false positive.
  4. Click Redact, then preview the result before saving it.

An option to skip images is available if a document's redaction doesn't need to cover embedded images. Redaction settings can be saved and reused across documents, so you don't have to redo the same review every time.

Just want to see what's in a document without producing a cleaned-up file? Use the PII Detector instead.
