PII Detector ​

The PII Detector scans a document and reports what personal information it finds, without changing the document at all — a quick first pass to check what's in a file before deciding what to do about it.

How it works ​

Drop in a PDF, CSV, or text file and click Run Detect. OrbySystems extracts the text and reports every likely personal detail it finds — names, account numbers, and similar — alongside the extracted text itself, so you can see exactly what was flagged and where.

When to use it instead of the PII Redactor ​

This tool only detects and reports; it doesn't produce a cleaned-up file. Detection from text matching and context is a useful first pass, but isn't reliable enough to depend on alone — when you actually need personal information removed from a document, use the PII Redactor instead.
